# Pitch deck content (12 slides, evidence-based, no invented numbers)

1. **Title** — JanSetu: AI Civic Intelligence for India.
2. **Problem** — Citizen development requests are fragmented across languages,
   channels, locations; demand stays invisible to planners.
3. **Why current approaches fragment demand** — Helplines, paper registers, and
   siloed portals never fuse into one geographic picture.
4. **JanSetu** — Voice/text → AI understanding → structured signal → hotspots →
   evidence → recommendations → simulator → dashboard.
5. **Citizen experience** — Type or speak in your language; get an "understood"
   confirmation, never a black box.
6. **AI architecture** — Gemini extracts/explains; deterministic Python computes.
   Validated outputs, template fallbacks, no LLM SQL or arithmetic.
7. **Data fusion** — Citizen signals × demographics × infrastructure ×
   investment, aggregated to state → district → locality.
8. **CivicPulse + hotspots** — Real 30d-vs-30d trends; ranked hotspots with
   every scoring factor exposed.
9. **Evidence-backed recommendations** — WHY checklists, facility counts,
   investment figures — auditable, labelled prototype analysis.
10. **Investment simulator** — "What could ₹50/100/250 Cr achieve?" Deterministic
    estimates with published assumptions, never guaranteed outcomes.
11. **Deployment + India-wide scale** — Cloud Run, district-agnostic pipeline,
    synthetic demo today, public datasets plug into the same schema.
12. **Impact + future** — Faster demand visibility for planners; next: live data
    partnerships, more languages, auth/audit trail. No partnerships claimed.
