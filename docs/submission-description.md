# Submission description

JanSetu turns multilingual citizen voice/text into structured civic demand with
Gemini, fuses it with demographic, infrastructure, and investment data, and gives
policymakers live hotspot maps, evidence-backed recommendations, and investment
scenario estimates.

It serves citizens (an "understood" confirmation in their language) and
policymakers (auditable, deterministic civic intelligence with AI explanations).

What makes it useful: every number is computed, never hallucinated — the AI
explains evidence it cannot invent, on clearly labelled synthetic demo data.
